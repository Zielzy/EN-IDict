# EN-IDict — Kamus Inggris - Indonesia untuk Yomitan

Kamus Bahasa Inggris - Indonesia untuk **Yomitan**.

---

## Cara Install

1. Download file `EN-IDict.zip` dari [GitHub Releases](https://github.com/Zielzy/EN-IDict/releases/latest).
2. Buka ekstensi **Yomitan** di browser.
3. Masuk ke **Settings** -> **Dictionaries** -> **Configure installed and enabled dictionaries...**
4. Klik **Import Dictionary...** lalu pilih file `EN-IDict.zip`.
